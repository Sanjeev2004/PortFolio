# Sanjeev Kumar - Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, experience, projects, and achievements as an AI/ML Engineer and Software Developer.

## 🧠 About Me
I'm a final-year B.Tech CSE student at Delhi Technological University (DTU) with a minor in Machine Learning (Class of 2026). I am passionate about building production-grade AI systems, LLM pipelines, and full-stack applications.

## 🛠️ Built With
* **HTML5** - Semantic structure and layout.
* **CSS3** - Custom properties, animations, Flexbox/Grid, and glassmorphism styling.
* **JavaScript** - Vanilla JS for interactive elements, typing effects, and scroll animations.

## ✨ Features
* **Modern & Responsive UI**: Glassmorphism design elements and responsive layout for all devices (desktop to mobile).
* **Interactive Elements**: Custom cursor glow, dynamic background grid, and scroll reveal animations.
* **Sections Included**:
  * Hero (Introduction & Social Links)
  * About (Background & Stats)
  * Skills (Programming, AI/ML, Web Dev)
  * Experience & Education (Timeline)
  * Projects (Featured AI/ML Work)
  * Achievements (Competitive Programming & Kaggle)
  * Contact (Functional form structure)

## 📂 Project Structure
* `index.html` - The main HTML structure of the website.
* `style.css` - Custom styling, responsive breakpoints, and animations.
* `script.js` - Dynamic interactions, intersection observers, and form validation.
* `avatar.png` - Profile picture.

## 🚀 Running Locally
To view the portfolio locally:
1. Clone the repository or download the files.
2. Open `index.html` in any modern web browser.
*(Alternatively, use a tool like VS Code Live Server for hot reloading during development.)*
